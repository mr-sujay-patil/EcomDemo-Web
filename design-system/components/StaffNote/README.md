# StaffNote

A short note written and signed by a real person: why a product is stocked, or a message on the order page.

This is the store's human surface: the one thing generated sites never have. A name, a role, a date, and a sentence only someone who used the product could write.

## Use
- One note per product page at most, under the description, and one on the order-confirmed page.
- Written by the person named, in the first person, in two sentences or fewer. Never generated, never written in someone else's name.
- Keep the date. An old note is fine; an undated one reads as filler.
- Set in Newsreader italic, the only italic in the interface.
- The words in the preview are placeholders: rewrite them in your own voice before the store goes live.
