# Chip

Chips are filter tags for the catalogue's categories: square-cornered, like the labels on a shelf.

## Use
- Labels are the catalogue's categories in title case (Peripherals, Displays, Audio, Storage, Accessories).
- `count` shows how many products match, in mono so the numbers line up.
- The selected tag is inked in (`ink-strong` fill, paper text), so selection is obvious in greyscale too.
- One tag is always selected; "Everything" is the default.
