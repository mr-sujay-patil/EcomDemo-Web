# Logo

The EcomDemo logo: a shipping tag on a loose piece of string, beside the name set in Newsreader, with *Demo* in italic.

The tag is what goes on every parcel the store sends, and the string is drawn slightly off, the way a real one falls. Colours come from `brand` and `ink-strong`, so the logo follows the theme.

## Use
- `variant="full"` in the header and on emails; `variant="mark"` for favicons, avatars and anything under 120px wide.
- Minimum height 20px (full) / 16px (mark). Clear space around it = the height of the tag.
- Never straighten the string, recolour the tag, or set the wordmark in another face.
- For `<img>` use the Logos assets (light and dark files); they carry fixed colours.
